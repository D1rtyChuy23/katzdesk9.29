Handoff for the builder

Single-file layout template of a barn warehouse board. Swap sample units for your inventory. Keep the structure; restyle tokens if needed.

  • Shell: dark ink sidebar (~248px) + cream paper canvas. Display serif for titles, Figtree for UI.
  • Page stack: title + lede + primary action → stat bubbles → “ready by model” bars → rack pills + search → color legend → bay grid → unit list.
  • Bays: back rack columns A–P, front rack I–P. Rows L4 (top) to L1 (floor). Slot ID = PALLET-L#, e.g. A-L3.
  • Cell number = lines used of 12. Empty / partial / full = muted / tint / solid primary. Catering A–D rust tint; dispensers E–F slate tint (back rack only).
  • Bubbles are filters (one at a time). Click again to clear. Counts stay unfiltered totals. Bay letters in the header also filter.
  • List row: slot · model + serial · status chips · qty. Opening a row would be a side sheet (not in this file).
